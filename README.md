# 铁塔 e 学自动学习助手

中国铁塔 e 学平台（elearning.chinatowercom.cn）的油猴（Tampermonkey）用户脚本，自动完成课程列表遍历、视频播放、章节切换、完结确认与下一门课程的衔接，减少人工重复操作。

当前版本：**v1.7.15** ｜ 运行环境：Chrome / Edge + Tampermonkey（Violentmonkey 亦可）

## 功能特性

### 自动学习主流程

- 自动识别课程 ID，支持分页课程列表遍历
- 自动过滤已完成课程、跳过指定课程（手动跳过名单持久化）
- 默认跳过末尾带考试/测验的课程（可检测考试页并暂停）
- 自动播放视频并按序切换章节
- “当前已是最后一节”弹窗自动确认，等待平台更新状态后自动关闭标签页
- 课程列表页自动刷新并打开下一门课程，形成连续学习队列
- “直接完结”课程（无弹窗）自动确认完成状态，修复早期版本卡住不跳转问题
- PPT/文档章节超过 7 分钟未完成视为加载异常，自动刷新重试

### 播放页能力

- 倍速播放开关与多档位（默认关闭，仅对 HTML5 视频生效；平台重置倍速时自动恢复）
- 倍速开启提示弹窗（“学习时长按实际学习时间统计……”）自动确认
- 面板实时显示学分 / 学时 / 章节进度
- 播放状态可通过标签页标题外露（可选的“标题调试”开关，默认关闭，标签名与未安装插件时完全一致）

### 界面

- 可拖动、可缩放的悬浮控制面板
- 课程列表面板不逐条显示已完成课程，减少冗余
- 开始 / 暂停、手动跳课、状态消息实时展示

### 可靠性

- 播放页与列表页之间的信号传递增强（关闭前通知列表页衔接下一课）
- 完结轮询链抗断裂：路由瞬态、接口异常不再导致等待状态无限循环
- 超时兜底：平台未及时更新完成状态时，刷新页面重查一次；仍无状态则凭“弹窗已确认 + 视频已播完”强制进入下一课
- 最后一节弹窗确认状态持久化（localStorage），刷新后不丢失

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. 点击 Tampermonkey 图标 → “添加新脚本”；
3. 将本仓库的 `tower-study-helper.js` 全文粘贴进去并保存（或直接导入该文件）；
4. 打开铁塔 e 学课程列表页，页面右侧会出现悬浮控制面板。

> 脚本匹配地址：`https://elearning.chinatowercom.cn/*`，`@run-at document-start`，`@grant none`（无额外权限，不访问跨域接口）。

## 使用说明

1. 打开平台课程列表页，脚本自动识别课程并填充面板；
2. 点击面板上的开始按钮启动自动学习；
3. 播放页会自动切章、确认完结弹窗，完结后自动关闭并回到列表页刷新、打开下一门；
4. 需要跳过某门课时使用面板的跳过功能，跳过名单会持久保存；
5. 倍速播放默认关闭，可在面板按需开启（注意：学习时长按实际学习时间统计，与倍速无关）。

## 已知限制

- Chrome/Edge 不支持 `window.open` 后台打开标签页，脚本自动开课时新标签会在前台打开（曾尝试 v1.7.16/17 的焦点归还方案，效果不稳定已回退）；
- 平台页面结构变更（选择器、弹窗文案）可能导致识别失效，届时需要更新脚本；
- 脚本行为依赖平台接口响应节奏，网络异常时会通过重试与超时兜底，但不保证 100% 自动衔接。
