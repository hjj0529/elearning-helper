# 铁塔 e 学自动学习助手

中国铁塔 e 学平台（elearning.chinatowercom.cn）的油猴（Tampermonkey）用户脚本，自动完成课程列表遍历、视频播放、章节切换、完结确认与下一门课程的衔接，减少人工重复操作。

当前版本：**v1.7.38** ｜ 运行环境：Chrome / Edge + Tampermonkey（Violentmonkey 亦可）

## 功能特性

### 自动学习主流程

- 自动识别课程 ID，支持分页课程列表遍历
- 自动过滤已完成课程、跳过指定课程（手动跳过名单持久化）
- 默认跳过末尾带考试/测验的课程（可检测考试页并暂停）
- 自动播放视频并按序切换章节
- 当前页学完后自动点击"下一页"翻页，逐页学习直到最后一页（多页自动学习）
- 学完自动衔接下一课且不重开刚学完的课程：完成信号键单边消费不被播放页抢走、状态写回不覆盖进度、独立“本会话已学完”清单硬跳过、列表刷新后等数据稳定+缓冲数秒再取状态选课，杜绝“开→已完成→关→再开”死循环
- 翻页后课程 ID 识别自动重试（每 2 秒一次、最长 30 秒），翻页点击失效时自动重试一次，慢网络下不中断
- “当前已是最后一节”弹窗自动确认，等待平台更新状态后自动关闭标签页
- 课程列表页自动刷新并打开下一门课程，形成连续学习队列
- “直接完结”课程（无弹窗）自动确认完成状态，修复早期版本卡住不跳转问题
- PPT/文档章节超过 7 分钟未完成视为加载异常，自动刷新重试
- 选课顺序可选：面板下拉提供"顺序学习"（默认，列表页从上到下）、"倒序学习"、"高学时优先"、"低学时优先"；点开始学习后按选定顺序构建队列，学完一课后按此顺序继续，运行中更改立即重排剩余队列
- 后台学习开关（面板勾选，**默认开启**）：课程列表页与播放页在**同一个标签内**完成后台切换——开课=同标签导航到详情页，学完=同标签导航回列表页并整页加载（复用既有续学流程）；全程不新开标签、不抢焦点，你在其它标签/窗口干活完全不受打扰；取消勾选即恢复原来的"新标签前台打开"方式（此路径与 v1.7.33 逐行一致），运行中取消勾选会在下次点"开始学习"后生效；**该开关跨标签双向同步**——在课程列表页或播放页改都生效，另一页面的面板勾选立即跟随并给出提示，写回状态前也先采纳持久化最新值，不会被旧内存值覆盖（v1.7.34 / v1.7.36）

### 播放页能力

- 倍速播放开关与多档位（默认关闭，仅对 HTML5 视频生效；平台重置倍速时自动恢复）
- 倍速开启提示弹窗（“学习时长按实际学习时间统计……”）自动确认
- 面板实时显示学分 / 学时 / 章节进度
- 标签页标题恒与平台一致（原“标题调试”功能已于 v1.7.21 移除，不再写入任何状态后缀）

### 界面

- 可拖动、可缩放的悬浮控制面板
- 课程列表面板不逐条显示已完成课程，减少冗余
- 开始 / 暂停、手动跳课、状态消息实时展示
- 面板按钮“返回列表”：暂停当前学习并回到课程列表，**并恢复到离开前所在的分页**（分页是平台客户端状态、整页加载必然重置回第 1 页，脚本回列表后按记录页码自动跳回）——后台模式下同一标签导航返回，双标签模式下关闭本播放标签回到列表标签（关闭失败退回导航），已在列表页时仅提示；返回后不会自动继续，想接着学再点“开始学习”（v1.7.35 新增，v1.7.38 补页码恢复 + 按钮名由“返回课程列表”简化为“返回列表”）

### 可靠性

- 播放页与列表页之间的信号传递增强（关闭前通知列表页衔接下一课）
- 播放页当页队列耗尽时交回列表页处理：由列表页刷新取最新状态后继续选课或自动翻页，不在播放页就地暂停造成全局停摆（v1.7.24）
- 播放器加载等待：PPT/文档章节或慢网络下播放器加载慢时，先进入"等待播放器加载"状态（90 秒窗口内每 10 秒刷新已等待秒数）并持续重试，播放器一出现立即接管自动播放，不再误报"未发现可控制的播放器"（v1.7.25）
- PPT 章节播放器启动：无 `<video>`、无 `.play-btn` 的 PPT/文档章节（页面只有大播放按钮），播放器区域出现后先缓冲 2 秒等就绪再点击大播放按钮，播放迹象（按钮消失/出现暂停控件）未确认时按 4/8/16/30 秒指数退避重试；找不到控件时打印容器 DOM 到控制台供排查（v1.7.27）
- 页码恢复：列表页整页刷新后分页重置回第 1 页时，按分页器高亮校准的页码恢复——刷新恢复与队列耗尽时优先"点页码直达"，未渲染目标页码则连续点"下一页"快进（不逐页构建队列）；学完第 N 页不再从第 1 页逐页重走（v1.7.28）
- 跨标签设置双向同步：选课顺序/队列排序由列表页变更、进度字段由播放页推进，两边写回互不覆盖（写入前采纳对端拥有的字段）；学习中在列表页改选课顺序，学完当前课立即按新顺序选下一课（v1.7.29）
- 播放页黑屏自愈：进入新播放页/新章节后延迟 10 秒再尝试点击播放（页面未加载完就点击容易偶发黑屏，v1.7.30 的 5 秒仍偏快已放宽）；`<video>` 已存在且**无任何加载进展**（currentTime/readyState/缓冲均不变）持续 30 秒才自动刷新播放页，刷新后 60 秒仍无进展且本页从未播上过才按"手动标记跳过"同款方式写入跳过名单（面板可取消）并续学下一课；慢网络下有加载进展即重置计时（不误判）、计时记录超 10 分钟过期、学一半中途卡死的课改为暂停等人工不跳过（v1.7.30，v1.7.31 修复误跳过回归）
- 视频"假结束"误报自愈：`ended` 后等待平台标记完成的轮询为单例定时器（多次 `ended` 不再叠加），视频恢复播放（平台回跳/人工拖进度/自动重播）立即自我取消等待；"视频结束，但平台尚未标记完成"消息在确认视频仍在播时自动纠正为"正在播放"（v1.7.32）
- 视频中途"假卡死"误报修复：平台防挂机机制在视频学习中途暂停视频（人工点一次播放即恢复，视频本身并未卡死）时，不再误报"视频学习中途卡死且刷新未能恢复，已暂停"——新增"健康暂停"判定（暂停 + 无错误 + readyState≥HAVE_FUTURE_DATA + 有数据源 + 缓冲覆盖当前位置即非卡死）：健康暂停不刷新页面、不标记跳过，由自动恢复流程持续重试（3 分钟窗口，期间面板显示恢复进度），超窗才以准确的"视频已暂停且多次自动恢复未成功（平台可能要求人工点击确认继续），已暂停等人工"暂停并保留学习进度；视频恢复播放后面板消息自愈为"正在播放：第N节"；真卡死（缓冲推不动/黑屏/源损坏）仍走原有 30 秒刷新 → 60 秒跳过/暂停两级兜底（v1.7.33）
- 人工自由控制：未点"开始学习"前插件对分页零干预（页码校准为纯读取），人工翻到某页再点开始即从该页起学
- 完结轮询链抗断裂：路由瞬态、接口异常不再导致等待状态无限循环
- 超时兜底：平台未及时更新完成状态时，刷新页面重查一次；仍无状态则凭“弹窗已确认 + 视频已播完”强制进入下一课
- 最后一节弹窗确认状态持久化（localStorage），刷新后不丢失
- 会话保活：列表页用 Web Worker 定时器（不受后台标签降频影响）周期性发轻量同源心跳维持登录会话，防止挂机久了被平台登出；默认开启、10 分钟一次（5-60 分钟可调，面板可关）；心跳纯后台不改标题不碰焦点，不影响其他工作（v1.7.20 起为纯保活：不做登录态判定与告警）

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. 点击 Tampermonkey 图标 → “添加新脚本”；
3. 将本仓库的 `tower-study-helper.js` 全文粘贴进去并保存（或直接导入该文件）；
4. 打开铁塔 e 学课程列表页，页面右侧会出现悬浮控制面板。

> 脚本匹配地址：`https://elearning.chinatowercom.cn/*`，`@run-at document-start`，`@grant none`（无额外权限，不访问跨域接口）。

## 使用说明

1. 打开平台课程列表页，脚本自动识别课程并填充面板；
2. 点击面板上的开始按钮启动自动学习；
3. 播放页会自动切章、确认完结弹窗，完结后自动关闭并回到列表页刷新、打开下一门；
4. 需要跳过某门课时使用面板的跳过功能，跳过名单会持久保存；
5. 倍速播放默认关闭，可在面板按需开启（注意：学习时长按实际学习时间统计，与倍速无关）。

## 已知限制

- **“后台学习”是“同标签后台切换”，不是“后台新标签”**：浏览器不允许页面脚本把新开的标签放到后台（实测无手势 `window.open` 仍会抢焦点），因此勾选后自动化只使用你打开的那**一个标签**（它轮流当课程列表页和播放页），该标签不能关闭；取消勾选可回到原来的多标签方式；
- 后台模式下若平台中途暂停视频要求人工点击确认，仍需你点一次（`v1.7.33` 会以“已暂停等人工”提示，不会误跳过课程）；
- Chrome/Edge 不支持 `window.open` 后台打开标签页，不勾选“后台学习”时自动开课的新标签会在前台打开（曾尝试 v1.7.16/17 的焦点归还方案，效果不稳定已回退）；
- 平台页面结构变更（选择器、弹窗文案）可能导致识别失效，届时需要更新脚本；
- 脚本行为依赖平台接口响应节奏，网络异常时会通过重试与超时兜底，但不保证 100% 自动衔接。
