# e 学自动学习助手

在线学习平台 e 学的油猴（Tampermonkey）用户脚本：自动遍历课程列表、播放视频、切换章节、确认完结并衔接下一门课程，减少重复的人工操作。

- 当前版本：**v1.7.41**
- 运行环境：Chrome / Edge + [Tampermonkey](https://www.tampermonkey.net/)（Violentmonkey 亦可）
- 版本历史：[CHANGELOG.md](CHANGELOG.md)

## 功能特性

### 自动学习

- 自动识别课程并构建学习队列，支持分页列表逐页学习
- 自动过滤已完成课程；支持手动"标记跳过"（名单持久化，面板可取消）
- 默认跳过末尾带考试/测验的课程（识别到考试页会暂停）
- 自动播放视频、按序切换章节、自动确认"当前已是最后一节"等完结弹窗
- 当前页学完自动翻页直到最后一页；学完自动衔接下一门，且不会重开刚学完的课程
- 选课顺序可选：顺序学习（默认）/ 倒序学习 / 高学时优先 / 低学时优先，运行中更改立即重排剩余队列
- **后台学习开关（默认开启）**：课程列表页与播放页在同一个标签内完成切换，全程不新开标签、不抢焦点，可在其它标签正常办公；取消勾选则恢复"新标签前台打开"方式

### 播放页与面板

- 倍速播放开关与多档位（默认关闭，仅对 HTML5 视频生效；平台重置倍速时自动恢复），并自动确认倍速提示弹窗
- 面板实时显示学分 / 学时 / 章节进度与课程 ID
- 面板按钮：开始学习 / 暂停 / 刷新识别 / 返回列表（返回列表会**恢复到离开前所在的分页**）
- 可拖动、可缩放的悬浮面板；课程列表不逐条显示已完成课程

### 可靠性

- 列表页与播放页信号可靠传递；播放页队列耗尽时交回列表页处理，不会全局停摆
- 慢网络适配：播放器加载等待与持续重试、翻页后课程 ID 识别自动重试（最长 30 秒）
- 播放页黑屏/真卡死自愈：等待页面就绪后再点击播放；无加载进展持续 30 秒自动刷新播放页，仍不行才跳过续学（仅限从未播上过的课，面板可取消）
- 平台防挂机暂停（需人工点一次播放）不再误判为"卡死"：识别为健康暂停并持续尝试自动恢复，超时以"已暂停等人工"提示，不误跳过课程
- "假结束"误报自愈：等待平台标记完成的轮询为单例，确认视频仍在播时自动纠正提示
- 完结轮询抗断裂 + 超时兜底：平台未及时更新状态时刷新重查，仍无状态则凭"弹窗已确认 + 视频已播完"强制进入下一课
- 会话保活：列表页用 Web Worker 定时心跳（不受后台标签降频影响）维持登录会话，默认 10 分钟一次（5-60 分钟可调，面板可关）
- 页码恢复与"页不重走"：整页刷新后按记录页码自动跳回，多页场景不逐页重走已完成页

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. 点击 Tampermonkey 图标 →"添加新脚本"，把本仓库的 `elearning-helper.js` 全文粘贴进去并保存；

   仓库若设为**公开**，也可以直接打开脚本地址、由 Tampermonkey 接管安装（这样后续能自动检查更新）：

   ```
   https://raw.githubusercontent.com/hjj0529/elearning-helper/main/elearning-helper.js
   ```

3. 打开平台课程列表页，页面右侧会出现悬浮控制面板。

> 生效范围由脚本头部 `@match` 限定（仅在该在线学习平台域名下运行）；`@run-at document-start`，`@grant none`（无额外权限，不访问跨域接口）。

## 使用说明

1. 打开平台课程列表页，脚本自动识别课程并填充面板；
2. 点击面板"开始学习"启动自动化，之后自动切章、确认完结、衔接下一门课程；
3. 需要跳过某门课时使用面板的"标记跳过学习"，跳过名单会持久保存；
4. 想中途停下或回列表：点"暂停"或"返回列表"（返回后不会自动继续，再点"开始学习"即可接上）；
5. 倍速播放默认关闭，可在面板按需开启（注意：学习时长按实际学习时间统计，与倍速无关）。

## 已知限制

- **"后台学习"是"同标签后台切换"，不是"后台新标签"**：浏览器不允许页面脚本后台打开新标签（实测无手势 `window.open` 仍会抢焦点），因此勾选后自动化只使用你打开的**那一个标签**（它轮流当课程列表页和播放页），该标签不能关闭；取消勾选可回到多标签方式；
- 平台中途暂停视频要求人工确认时，仍需你点一次播放（脚本会提示"已暂停等人工"，不会误跳过课程）；
- 不勾选"后台学习"时，自动开课的新标签会在前台打开（曾尝试焦点归还方案，效果不稳定已回退）；
- 平台页面结构或文案变更可能导致识别失效，届时需要更新脚本；
- 脚本行为依赖平台接口响应节奏，网络异常时有重试与超时兜底，但不保证 100% 自动衔接。
